Which would you rather receive?

Blind comparison of AI-written messages. About 15 minutes.

For each request, imagine you are the person the message is going to. Pick the one you would rather receive, given what the sender needed to say. Tick feels put-on on any message that seems fake, stereotyped or over-polite. The order is random and the sources are hidden. When you finish, press Download my votes and send the file back.
